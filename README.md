# 眠豆腐年度穩定先生 MR. STABLE 2026

眠豆腐 × TYC LEAGUE 年度穩定先生粉絲投票網頁。

## 檔案
- `index.html`：整個網頁（文字、隊友 Q&A、精華句、投票方式都在這裡）
- `img/`：9 位候選人照片

## 常改的地方（都在 index.html 的 `<script>` 裡）
- `VOTE_URL`、`THREADS_URL`：投票按鈕連結
- `QA`：每位候選人的隊友 Q&A（`qa`）、精華句（`hl`）、署名（`by`）
- `EX`：每位候選人的「穩」造句範例
- `PLAYERS`：候選人基本資料與 TYC LEAGUE 觀察

## 發佈
GitHub Pages：Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`。
